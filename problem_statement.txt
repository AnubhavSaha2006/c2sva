Project 4: Automatic Generation of RTL Assertions (LTL/SVA) from C-Level Preconditions and Postconditions for HLS Designs 

Many of the C code is already annoted with many safety, security and correctness properties. If we synthesize the C code to RTl, how do we take those C properties into RTL? Write a tool with the help of LLM for this.  

Questions to address. 

How can untimed C contracts be mapped to timed RTL properties?  

How can source variables be related to HLS-generated RTL signals?  

How should variable and dynamic latency be handled?  

How can array and memory properties be translated?  

How robust is the method across different HLS optimizations?  

Can an LLM assist the translation while formal analysis validates the generated assertions?
